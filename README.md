# Party Calculator

자캐 파티 운영용 레벨/경험치/스탯/데미지 계산기입니다.



## 현재 포함 기능

- 원페이지 3열 레이아웃
- 여러 캐릭터 등록/선택/삭제
- 캐릭터 이미지 URL 선택 입력
- 캐릭터별 레벨/경험치/스탯 저장
- 경험치 규칙: 현재 레벨 × 5,000
- 다중 레벨업 처리
- 레벨업 1회당 총 10포인트 랜덤 스탯 분배
- 물리 데미지: `(힘 + 민첩) × 2~3.5`
- 마법 데미지: `(지능 + 마력) × 2~3.5`
- 크리티컬: 10% / 1.5배
- 캐릭터별 레벨업 기록
- 캐릭터별 최근 데미지 계산 기록
- localStorage 자동 저장
- 모바일 반응형 초안

## 메모
- 캐릭터 수정 기능: 이름 / 이미지 URL / 레벨 / EXP / 4종 스탯 직접 보정
